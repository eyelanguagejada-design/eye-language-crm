# Eye Language CRM — تطبيق الموبايل

غلاف PWA بيفتح نظام CRM لغة العين (Google Apps Script) كتطبيق بيتثبت على الموبايل والكمبيوتر.

- لينك التثبيت: https://eyelanguagejada-design.github.io/eye-language-crm/install.html
- لينك التطبيق: https://eyelanguagejada-design.github.io/eye-language-crm/

## ملاحظات
- الكود نفسه مش هنا، ده في مشروع Apps Script (crm.ksa). الدالة `doGet` هناك بتنادي `EL_wrapForApp_` اللي بتسمح بالفتح جوه التطبيق وبتخلي التنقل بين الصفحات جوه التطبيق.
- لو عملت Deployment جديد بلينك مختلف، غيّر `APP_URL` في `index.html`.
- الأيقونة: `icon-192.png` و `icon-512.png`.
